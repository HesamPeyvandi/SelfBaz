# پایش سلف

اپ سبک اندروید که به‌صورت دوره‌ای بررسی می‌کند ناهارِ شنبه‌ی هفته‌ی بعد در سامانه‌ی سلف دانشگاه سمنان باز شده یا نه، و در صورت باز شدن اعلان می‌دهد.

## ساخت APK (بدون نیاز به Android Studio)
1. در GitHub یک repository جدید بسازید (ترجیحاً Public).
2. همه‌ی فایل‌های این پوشه را آپلود کنید (شامل پوشه‌ی `.github`).
3. تب **Actions** ← workflow به نام **Build APK** ← اگر خودکار اجرا نشد، **Run workflow**.
4. پس از ~۵ دقیقه، داخل همان اجرا در بخش **Artifacts** فایل `SelfWatch-apk` را دانلود کنید و از zip خارج کنید.
5. فایل `app-release.apk` را روی گوشی نصب کنید (اجازه‌ی «نصب از منبع ناشناس»).

## امنیت
- رمز با Android Keystore رمزنگاری و فقط روی همان گوشی ذخیره می‌شود؛ بکاپ خاموش است.
- فقط به دامنه‌ی `*.semnan.ac.ir` و فقط با HTTPS درخواست می‌زند (حتی در ریدایرکت‌ها).
- بدون آنالیتیکس، تبلیغ و سرور واسطه. رمز هرگز لاگ نمی‌شود.
- با رمز اشتباه، پایش خودکار متوقف می‌شود تا حساب قفل نشود.

## مصرف باتری
بین دو بررسی هیچ کدی اجرا نمی‌شود (فقط آلارم سیستم). هر بررسی چند درخواست HTTP کوچک است.
خارج از روزهای فعال هیچ بررسی‌ای انجام نمی‌شود. حداقل فاصله‌ی بررسی ۲ دقیقه است.

## محدودیت‌ها
- حساب‌های دارای رمز دوم (پیامکی/Authenticator) پشتیبانی نمی‌شوند.
- اگر ساختار سایت سلف عوض شود، برنامه خطا می‌دهد و باید به‌روز شود.
